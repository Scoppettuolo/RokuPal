RokuPal 1.0.0
=============

RokuPal is a self-contained CMS fork (Drupal 6 API lineage) focused on
blogs, forums and simple sites. It is not "Drupal 6" branding — the product
name is RokuPal.

Install
-------
1. Copy this folder under your web root (e.g. htdocs/rokupal).
2. Open install.php in the browser.
3. Choose SQLite or MySQL and create the admin account.
4. Blog preset is enabled by default.

Admin
-----
- Modules: admin/build/modules  (RokuPal Modules Manager)
- Colors:  admin/settings/color
- Filters: admin/settings/filters  (Markdown format)

Requirements
------------
PHP 7.4+ recommended (PHP 8 supported with RokuPal patches).
SQLite or MySQL/MariaDB.

Version
-------
RokuPal 1.0.0
